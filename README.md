World in a Day — Sunday, 22 November 2026: the world's news summed up in one 1024×1024 front-page image. Forty stories, from the collapse of COP31 in Antalya and Ukraine sinking the Russian corvette Merkury at Benghazi to the Dymer strike, the Hormuz tanker attacks, the Democrats' largest House majority since 1992 and Alcaraz's first ATP Finals crown, set as a classic newspaper front page with a day-in-numbers strip. The program at main.ts copies the page (entry.png) to the output directory; stories.json holds the day's stories with their date evidence, build_page.mjs sets the page, and render.mjs screenshots it at exactly 1024×1024.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
